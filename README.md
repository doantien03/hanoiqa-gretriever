## Quy trình làm việc
1. Lấy code mới nhất từ main.
2. Tạo nhánh riêng cho từng công việc.
3. Viết code và chạy kiểm tra.
4. Push nhánh lên GitHub.
5. Tạo Pull Request vào main.
6. Một thành viên khác review trước khi merge.

Không push trực tiếp vào main.
Không đưa API key hoặc checkpoint lên repository.
